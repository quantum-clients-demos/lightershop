# Ember & Co. Backend API

FastAPI modular backend powering the Ember & Co. luxury lighter e-commerce platform.

## Features
- Dual pricing modes: Retail & Wholesale B2B
- Razorpay Payment Gateway integration
- PostgreSQL / Supabase async database with SQLAlchemy & asyncpg
- JWT authentication and role-based access control
- Product catalog, tiers, orders, and consignment tracking
